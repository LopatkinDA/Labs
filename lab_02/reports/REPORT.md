### 3 Поверхностное и глубокое копирование

Прогноз: append изменит original и alias; замена оценки во вложенном списке изменит также shallow. Глубокая копия сохранит исходные оценки. Фактические состояния приведены в таблице 2.

Таблица 2 — Состояния после двух последовательных изменений

| Структура | После append | После original[0][1] = 3 |
| --- | --- | --- |
| original | Python 5; Algorithms 4; Databases 5 | Python 3; Algorithms 4; Databases 5 |
| alias | Python 5; Algorithms 4; Databases 5 | Python 3; Algorithms 4; Databases 5 |
| shallow | Python 5; Algorithms 4 | Python 3; Algorithms 4 |
| deep | Python 5; Algorithms 4 | Python 5; Algorithms 4 |

Внешние id совпадают только у original и alias. Первый вложенный список общий у original, alias и shallow; у deep он другой. После замены оценки первые три структуры ссылаются на число 3, deep — на 5. До замены id числа 5 совпадал во всех структурах: deepcopy не обязан создавать копию неизменяемого числа.

Таблица 3 — Свойства способов копирования

| Операция | Новый внешний объект | Новые вложенные объекты | Независимость изменений |
| --- | --- | --- | --- |
| Присваивание | Нет | Нет | Нет |
| Поверхностная копия | Да | Нет | Только состав внешнего списка |
| Глубокая копия | Да | Да для вложенных списков | Да для исследованной структуры |

Прогноз для матриц: умножение внешнего списка повторяет ссылки на одну строку. После wrong_matrix[0][0] = 1 получены три строки [1, 0, 0] с одинаковыми id. В списковом включении каждая строка создается отдельно: correct_matrix равна [[1, 0, 0], [0, 0, 0], [0, 0, 0]], id трех строк различны. Прогноз подтвержден.

Ответы на вопросы. Поверхностная копия создает новый контейнер, сохраняя ссылки на вложенные объекты. Глубокая копия рекурсивно копирует поддерживаемые изменяемые компоненты с учетом уже посещенных объектов. Она требует дополнительных памяти и времени, может копировать излишние данные и не является универсальным способом копирования файлов, сокетов и других ресурсов. Поверхностной копии достаточно при изменении только внешнего контейнера или при неизменяемых элементах.

### 4 Подсчет ссылок и время жизни

Прогноз: alias и помещение data в контейнер увеличат счетчик на 1; del alias и container.clear() уменьшат его на 1. Фактические значения в таблице 4 соответствуют прогнозу.

Таблица 4 — Изменение счетчика ссылок

| Шаг | sys.getrefcount(data) | Изменение |
| --- | --- | --- |
| Создание data | 2 | База |
| Создание alias | 3 | +1 |
| container = [data] | 4 | +1 |
| del alias | 3 | −1 |
| container.clear() | 2 | −1 |

sys.getrefcount получает объект как аргумент, что добавляет временную сильную ссылку на время вызова. Поэтому при одном имени data показано 2. del удаляет привязку имени: объект продолжает жить, если к нему существуют другие сильные ссылки. Для обычного нециклического объекта CPython освобождает объект при падении счетчика до нуля.

Прогноз для слабой ссылки: после del record weak_record() вернет None. Фактически до удаления получен объект Record, после — None. Слабая ссылка позволяет найти объект, пока он жив, но не увеличивает число удерживающих его сильных ссылок. Например, слабый кэш может хранить уже созданные объекты, не мешая их освобождению после закрытия всех использующих их документов.

Прогноз для WeakValueDictionary: ключи a, b, c; после del temporary — a, b; после del a — только b. Вывод запуска полностью совпал с прогнозом. Для b сохранялась отдельная сильная ссылка, и registry['b'] is b проверено через assert.

Ответы на вопросы. Нулевой счетчик позволяет освободить обычный объект; цикл требует отдельного анализа достижимости. Освобождение Python-объекта не гарантирует немедленный возврат памяти операционной системе: аллокатор может сохранять освобожденные блоки для повторного использования. Сильная ссылка удерживает объект, слабая не управляет его временем жизни.

Поколения позволяют чаще проверять молодые объекты, многие из которых живут недолго, и реже — пережившие сборки. Прогноз подтвердился: размер меняется не при каждом append. Длина — число доступных элементов, а емкость — число зарезервированных мест для ссылок. Запас уменьшает частоту перераспределений, благодаря чему append имеет амортизированную сложность O(1).

Для уменьшения лишнего потребления памяти следует использовать range или генератор вместо полной материализации, если данные нужны последовательно; создавать поверхностную копию вместо deepcopy, когда вложенные данные не меняются; удалять ненужные сильные ссылки и применять слабый реестр для необязательного кэша.
```python
"""Измерения памяти для задания 5."""
import gc
import sys
import tracemalloc


def measure(name):
    """Создаем один объект и сохраняем результаты измерения."""
    gc.collect()
    tracemalloc.start()
    if name == 'empty list':
        obj = []
    elif name == 'list 10':
        obj = list(range(10))
    elif name == 'tuple 10':
        obj = tuple(range(10))
    elif name == 'string 10':
        obj = 'abcdefghij'
    elif name == 'int':
        obj = 1000
    elif name == 'None':
        obj = None
    elif name == 'list 100000':
        obj = list(range(100_000))
    elif name == 'range 100000':
        obj = range(100_000)
    current, peak = tracemalloc.get_traced_memory()
    tracemalloc.stop()

    if name == 'int' or name == 'None':
        count = 1
    else:
        count = len(obj)
    return {
        'scenario': name,
        'elements': count,
        'outer_bytes': sys.getsizeof(obj),
        'current_bytes': current,
        'peak_bytes': peak,
    }


def collect_measurements():
    names = ['empty list', 'list 10', 'tuple 10', 'string 10',
             'int', 'None', 'list 100000', 'range 100000']
    rows = []
    for name in names:
        rows.append(measure(name))

    # Сохраняем только шаги, на которых изменился размер списка.
    values = []
    old_size = sys.getsizeof(values)
    growth = [(0, old_size)]
    for value in range(100):
        values.append(value)
        new_size = sys.getsizeof(values)
        if new_size != old_size:
            growth.append((len(values), new_size))
            old_size = new_size

    list_peak = rows[6]['peak_bytes']
    range_peak = rows[7]['peak_bytes']
    ratio = list_peak / range_peak
    return {'rows': rows, 'growth': growth, 'peak_ratio': ratio}


def print_measurements(data):
    print('scenario | elements | outer B | current KiB | peak KiB')
    for row in data['rows']:
        current_kib = row['current_bytes'] / 1024
        peak_kib = row['peak_bytes'] / 1024
        print(row['scenario'], row['elements'], row['outer_bytes'],
              round(current_kib, 3), round(peak_kib, 3), sep=' | ')
    print('Рост списка (длина, байт):', data['growth'])
    print('Отношение пиков list/range:', round(data['peak_ratio'], 2))


def main():
    print('Прогноз: список растет ступенями; range занимает меньше памяти.')
    data = collect_measurements()
    assert data['rows'][6]['peak_bytes'] > data['rows'][7]['peak_bytes']
    assert data['rows'][6]['elements'] == 100_000
    assert data['rows'][7]['elements'] == 100_000
    print_measurements(data)


if __name__ == '__main__':
    main()
```

```python
"""Имена, ссылки и независимые конфигурации."""
from copy import deepcopy


def main():
    print('Прогноз A: сначала один int; после += значения 11 и 10.')
    a = 10
    b = a
    print(a, b, id(a), id(b))
    a += 1
    print(a, b, id(a), id(b))
    assert (a, b) == (11, 10) and a is not b
    print('Прогноз B: append общий; после копирования изменения независимы.')

    print(first, second, id(first), id(second))
    second.append(30)
    print(first, second, id(first), id(second))
    second = list(first)
    print('После переназначения: ==', first == second, 'is', first is second)
    second.append(40)
    print(first, second)
    assert first == [10, 20, 30] and second == [10, 20, 30, 40]
    print('Прогноз: присваивание разделяет весь словарь; deepcopy изолирует списки.')
    config = {'name': 'Учебный проект', 'members': ['Анна'],
              'launch': [['--port', '8000'], ['--debug', 'off']]}
    alias = config
    print('До:', config, alias)
    alias['members'].append('Борис')

    print('После общего изменения:', config, alias)
    independent = deepcopy(config)
    print('До независимого изменения:', config, independent)
    independent['members'].append('Дарья')
    independent['launch'][0][1] = '7000'
    print('После:', config, independent)
    assert alias is config
    assert independent is not config
    assert independent['members'] is not config['members']
    assert independent['launch'][0] is not config['launch'][0]
    assert config['members'] == ['Анна', 'Борис']
    assert config['launch'][0][1] == '9000'
    print('Итог: alias общий; independent и его изменяемые списки независимы.')
```

```python
            del cycle

        before = gc.collect()
        a = {'name': 'A', 'edges': []}
```
