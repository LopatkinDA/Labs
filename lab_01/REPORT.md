Использован CPython 3.12.14, Windows 11, 64 бита. Проверка выполнена 24 ноября 2026 года. Файлы task_1.py–task_5.py запускаются командой python task_N.py из каталога lab_01. Условия, циклы, коллекции, пользовательские функции и обработка исключений в этих файлах не используются. Это дополнительно проверено по дереву AST. Для форматирования через % каждый аргумент подставляется отдельно, без создания кортежа.

В настоящем интерактивном интерпретаторе выражение 2 + 3 * 4 вывело 14. В task_1.py сначала записано выражение без print, затем print того же выражения. Файл вывел 14 только один раз. REPL автоматически показывает результат выражения, кроме None, а выполнение файла само по себе не печатает результат. Компилятор также может убрать бесполезное постоянное выражение.

Команды исследования:

```text
python --version
python -m ast task_1.py
python -m dis task_1.py
```

В task_1.py выражениями являются литералы 2, 3, 4, строки, 3 * 4, 2 + 3 * 4, 4 * 2, f-строка и вызов print(). Присваивания course = 'Python' и hours = 4 * 2 — инструкции. Вызов print на отдельной строке — инструкция-выражение. Имена course и hours создаются присваиваниями; имя print уже доступно из встроенной области. Модульная строка документации связывается с __doc__.

Фрагмент фактического AST:

```text
Assign(
  targets=[Name(id='hours', ctx=Store())],
  value=BinOp(left=Constant(value=4), op=Mult(),
              right=Constant(value=2)))
Expr(value=Call(func=Name(id='print', ctx=Load()), ...))
```

Фрагмент фактического байткода:

```text
LOAD_NAME    (print)
LOAD_CONST   (14)
CALL         1
POP_TOP
LOAD_CONST   ('Python')
STORE_NAME   (course)
LOAD_CONST   (8)
STORE_NAME   (hours)
```

В AST сохранилась операция умножения 4 * 2, а в байткоде уже загружается константа 8: компилятор свернул постоянное выражение. LOAD_CONST загружает константу, CALL вызывает функцию, STORE_NAME связывает имя с результатом. Байткод — команды виртуальной машины CPython, а не машинные инструкции конкретного процессора.

### 2 Имена объекты и сравнение

Прогнозы записаны комментариями перед запуском: a == b, a is b и a == c дадут True; a is c — False в данном опыте с int('1000'). Фактически получены True, True, True, False. Все три объекта имеют тип int. Адреса a и b совпали, адрес c отличался; конкретные числа id зависят от запуска.

```text
a ──┐
    ├──> объект int со значением 1000
b ──┘
c ─────> другой объект int со значением 1000

После c = None:
c ─────> None
```

Рисунок 1 — Имена и объекты

После c = None проверка c is None дала True. Присваивание b = a не создало копию. type возвращает класс объекта, id — идентификатор объекта, уникальный среди одновременно существующих объектов. Равенство значений проверяется через ==, идентичность — через is. По различию id нельзя заключить, что значения не равны.

Для first = 'python' и second = 'py' + 'thon' фактически оба сравнения дали True. Это согласуется со сворачиванием строкового выражения и совместным использованием константы; гарантировать такой результат is для произвольных строк нельзя. None — единственный специальный объект отсутствующего значения, поэтому его проверяют через is None. Числа и строки обычно сравнивают через ==.

### 3 Числовые операции и преобразования

Прогноз: для int только обычное деление в данном наборе даст float. Результаты совпали с прогнозом.

Таблица 1 — Арифметика для x = 17 и y = 5

| Операция | Результат | Тип |
| --- | --- | --- |
| + | 22 | int |
| − | 12 | int |
| * | 85 | int |
| / | 3.4 | float |
| // | 3 | int |
| % | 2 | int |
| ** | 1419857 | int |

Обычное деление / дает вещественное частное даже для двух int. Операция // округляет частное вниз; для двух int результат int, но при вещественном операнде может быть float. Вычислено 2 ** 1000 — положительное целое из 302 десятичных цифр без переполнения фиксированной разрядности. Python увеличивает объем памяти целого по необходимости; доступная память все же ограничена.

Прогноз опыта float: 0.1 + 0.2 не будет точно равно 0.3. Фактически result = 0.30000000000000004, сравнение == дало False, разность 5.551115123125783e-17, math.isclose — True. Десятичные дроби обычно не представимы точно в двоичной системе. Для приближенных вычислений используют выбранные по смыслу задачи относительную и абсолютную погрешности, а не произвольное точное равенство.

Таблица 2 — Явные преобразования

| Выражение | Значение | Тип |
| --- | --- | --- |
| int('42') | 42 | int |
| float('3.14') | 3.14 | float |
| str(2026) | '2026' | str |
| bool(0) | False | bool |
| bool(−1) | True | bool |
| bool('') | False | bool |
| bool('False') | True | bool |
| complex(2, −3) | (2−3j) | complex |

У комплексного числа действительная часть равна 2.0, мнимая −3.0. Непустая строка 'False' истинна: bool проверяет наличие содержимого, а не смысл слова. Из перечисленных входов falsy — 0 и пустая строка. int('42') разбирает строковую запись целого, int(42.9) отбрасывает дробную часть к нулю и дает 42.

Таблица 3 — Типы всех имен карточки

| Имена | Тип после присваивания |
| --- | --- |
| researcher, experiment | str |
| runs | int |
| duration, real, imag | float |
| total_seconds, total_minutes, squared_module | float |
| coefficient | complex |
| has_runs | bool |

В строке squared_module = real ** 2 + imag ** 2 имена real, imag обозначают входные числа, 2 — целочисленный литерал, ** и + — операторы. Вызовов функций в этой строке нет. Промежуточный результат сохраняется в понятном имени, а затем форматируется .2f.

Путь выполнения: исходный файл → разбор текста → AST → компиляция в байткод → выполнение виртуальной машиной CPython. input возвращает str, поэтому перед числовыми вычислениями нужны int и float. Повторное присваивание связывает имя с новым результатом; оно не изменяет ранее связанный неизменяемый объект. Старый объект может оставаться доступным через другие имена.

"""Проверяем числовые операции и преобразования."""
import math

x = 17
y = 5
# Прогноз: только обычное деление этих int дает float.
print('+', x + y, type(x + y))
print('-', x - y, type(x - y))

print('/', x / y, type(x / y))
print('//', x // y, type(x // y))
print('%', x % y, type(x % y))
print('**', x ** y, type(x ** y))

print('isclose:', math.isclose(result, 0.3))

print(float('3.14'), type(float('3.14')))
print(str(2026), type(str(2026)))
print(bool(0), type(bool(0)))
print(bool(-1), type(bool(-1)))
print(bool(''), type(bool('')))
print(bool('False'), type(bool('False')))
coefficient = complex(2, -3)
print(coefficient, type(coefficient))

print('Мнимая часть:', coefficient.imag)
