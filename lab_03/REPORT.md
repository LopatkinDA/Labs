### 3 Циклы и поиск

Для measurements = [12, 15, 11, 18, 18, 9, 21, 15, 7, 18] ожидались и получены: сумма 144, минимум 7, максимум 21, четных 4, среднее 14.4, выше среднего 6. Сначала одним циклом считаются сумма, минимум, максимум и четные. После этого вторым циклом считаются числа выше среднего.

Псевдокод подсчета для заданного непустого списка:

```text
сумма = 0; четные = 0
минимум = максимум = первый элемент
для каждого числа:
    добавить число к сумме
    обновить минимум и максимум
    если число четное: увеличить счетчик
среднее = сумма / длина списка
выше = 0
для каждого числа:
    если число > среднего: увеличить выше
вывести результаты
```

Линейный поиск 18 дал индекс 3 и 4 сравнения. Дополнительный запуск с 99 дал −1 и 10 сравнений. Поиск останавливается при первом совпадении.

Для проверки простоты делители перебираются, пока d*d <= number. Получено: 0, 1, 4, 49 — False; 2 и 97 — True. У составного числа хотя бы один множитель не больше его квадратного корня, поэтому дальше проверять не нужно.

Сортировка выбором ищет наименьший элемент оставшейся части и ставит его на очередное место. Копия [3, 1, 2, 1] стала [1, 1, 2, 3], исходный список сохранился. Бинарный поиск выполняется после сортировки.

Псевдокод бинарного поиска:

```text
левая = 0; правая = длина - 1; сравнения = 0
пока левая <= правая:
    середина = (левая + правая) // 2
    сравнения += 1
    если число в середине == цель:
        вернуть середину и сравнения
    сравнения += 1
    если число в середине < цели:
        левая = середина + 1
    иначе: правая = середина - 1
вернуть -1 и сравнения
```

При поиске первого элемента линейный поиск быстрее, но для дальних и отсутствующих элементов бинарный делает намного меньше сравнений.

Таблица 3 — Сложность алгоритмов

| Алгоритм | Время в худшем случае | Дополнительная память |
| --- | --- | --- |
| Подсчет в два прохода | O(n) | O(1) |

Множество убирает повторы. Кортеж из строк можно сделать ключом, потому что он неизменяем и его элементы имеют хеш. Список изменяем и ключом быть не может. Словарь позволяет найти результат сразу по паре, без просмотра всех записей.

У build_report параметры precision и prefix передаются только по имени. Проверены обычный вызов, вызов с именами student и results, а также build_report(*arguments, **options). Последний дал «Итог: Анна — 85.0». Для arithmetic_mean([]) получен ValueError.

Рисунок 1 — Области видимости LEGB

Поиск идет от L к E, G и B. marker находится в inner, course из-за nonlocal берется из outer, len — из встроенных имен. outer() вернула ('Локальный курс: обновлен', 8). Глобальное course не изменилось.

В bad_add_result список по умолчанию создается один раз, поэтому два вызова дали один список [1, 2]. В исправленной add_result значение по умолчанию — None. Каждый вызов создает отдельный список; явно переданный список копируется перед append.

apply_to_results с double дала [2,4,6], с lambda x: x+5 — [6,7,8]. Две функции из make_threshold_checker сохраняют разные threshold: для 75 проверка с порогом 60 дала True, с порогом 90 — False. Это значение хранится во внешней области функции, то есть в замыкании. apply_to_results обрабатывает n значений за O(n) времени и памяти. collect_tags в худшем случае требует O(n²) времени из-за поиска в списке, память результата — O(n).

Таблица 10 — Входы и результаты обязательных функций

| Функция | Допустимый вход | Результат и особые случаи |
| --- | --- | --- |
| mean(values) | Список конечных чисел | Среднее; [] → None |
| minimum(values) | Список конечных чисел | Минимум; [] → None |
| maximum(values) | Список конечных чисел | Максимум; [] → None |
| classify(score) | Балл 0..100 или None | Категория; None → «нет данных» |
| student_summary(name, results) | Имя str и список целых баллов 0..100 | Словарь: имя, число оценок, среднее, минимум, максимум, категория; [] допустим |
| group_summary(students) | Словарь имен и списков баллов | Общие счетчики, среднее, категории, лидеры, рейтинг; пустая группа допустима |

| format_report(student_data, group_data) | Список сводок и сводка группы | Строка отчета; None выводится словами «нет данных» |

Функции принимают корректные данные и не меняют входные коллекции. mean, minimum и maximum для k оценок работают за O(k), используют O(1) памяти. Для S студентов и M оценок group_summary требует O(M+S²) времени: подсчет линейный, рейтинг сортируется пузырьком. Дополнительная память — O(S). find_top_students работает за O(M+S), а format_report — за время и память, зависящие от длины текста.
