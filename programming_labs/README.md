## Запуск

Нужен Python 3.11 или новее. Проверено на CPython 3.12.14 под Windows 11.

Для работ 1–4 перейдите в нужную папку и запускайте файлы по одному:

```console
cd lab_01
python task_1.py
python task_2.py
python task_3.py
python task_4.py
python task_5.py
```

В работе 1 пятый файл запрашивает данные эксперимента. В работе 3 второй файл запрашивает искомое число. В работе 2 есть дополнительная утилита `python memory_report.py`.

Для работы 5 выполните из папки `lab_05`:

```console
python -m pip install -r requirements.txt
python -m pytest -q
python -m course_tracker
```

Полный список команд, настройка окружения и примеры импорта приведены в [инструкции CourseTracker](lab_05/README.md).
