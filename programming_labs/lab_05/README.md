# CourseTracker

Учебное консольное приложение для учета студентов, лабораторных и попыток сдачи. Требуется CPython 3.11 или новее. Само приложение использует только стандартную библиотеку. Для тестов нужен pytest.

## Установка и запуск

В Windows откройте терминал в папке lab_05:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m course_tracker
```

Для Linux и macOS вместо `.venv\Scripts\python.exe` используйте `.venv/bin/python`.

```text
python -m pytest -q
```

Тесты вызывают модели и сервис напрямую. Они не запускают CLI и не работают с настоящими файлами. Если зависимости установлены в окружение `.venv`, запускайте тесты его интерпретатором.

## Команды

Команды с именами, названиями и путями, содержащими пробелы, требуют двойных кавычек. В путях Windows удобно использовать `/`, например `data/students.csv`.

```text
help
exit
save
student add s001 "Анна Смирнова" P3120
student list
student list name
student list group
student list id
student show s001
student deactivate s001
student activate s001
student search смир
lab add lab_01 "Базовые типы" 100 2026-12-01 python,types
lab add lab_02 "Память" 100 2026-12-02 memory "Ссылки и копирование"
lab list
lab show lab_01
lab search python
submit s001 lab_01 87.5 "Первая попытка"
submission accept s001 lab_01 1
submission reject s001 lab_01 1 "Не пройдены проверки"
history s001
report student s001
report group
report lab lab_01
report missing
top 5
import students data/students.csv
import submissions data/submissions.csv
export json exports/report.json
export csv exports/report.csv
snapshot create
snapshot restore
undo
memory
memory profile
```

`exit` сохраняет состояние в `data/course.json`. При следующем запуске оно загружается автоматически. `save` сохраняет без выхода. Лог действий записывается в `logs/course_tracker.log`.

`undo` отменяет последнее успешное изменение. Перед каждой командой изменения создается независимая копия данных. При ошибке восстанавливается прежнее состояние. `snapshot create` сохраняет отдельный снимок, `snapshot restore` восстанавливает его. Восстановление снимка тоже можно отменить через `undo`. История отмены и снимок действуют только в текущем сеансе.

## Правила статистики

Среднее и лучший балл студента вычисляются по всем его попыткам, независимо от статуса. Работа считается сданной, только если есть хотя бы одна попытка со статусом `accepted`. Статус `submitted` означает, что попытка ожидает проверки. Если принятую попытку перевести в `rejected`, она перестает давать прогресс, если другой принятой попытки нет.

Рейтинг — средний процент лучших результатов по всем лабораторным: балл каждой работы делится на ее максимум и умножается на 100; работа без попыток дает 0. Поэтому задания с разными максимумами сравнимы. `top N` включает всех студентов, разделивших балл на последнем включенном месте. При отсутствии работ рейтинг равен `None`; при наличии работ и отсутствии попыток — 0. Студенты без оценок имеют среднее и максимум `None`, что не подменяет отсутствие данных нулевой оценкой.

Общее среднее группы — среднее всех зарегистрированных баллов. При разных максимумах это среднее сырых баллов; распределение категорий и рейтинг считаются в процентах. Неактивный студент остается в истории и отчетах, но новые попытки ему не добавляются.

## Форматы данных

JSON содержит `version`, списки `students`, `laboratories`, `submissions` и вычисленную `summary`. Множества тегов сохраняются списками. Каждый студент содержит student_id, full_name, group, registered_at и active. Лабораторная содержит laboratory_id, title, description, max_score, deadline и tags. Попытка содержит student_id, laboratory_id, attempt, score, comment, status, submitted_at и max_score. Версия формата — 1. При загрузке статистика пересчитывается, а не принимается из поля summary.

Минимальный CSV студентов:

```csv
student_id,full_name,group
s001,Анна Смирнова,P3120
```

Минимальный CSV попыток:

```csv
student_id,laboratory_id,score,comment,status
s001,lab_01,87.5,Первая попытка,submitted
```

Перед импортом попыток создайте соответствующие работы и студентов. Поля comment и status необязательны; по умолчанию комментарий пустой, статус submitted. Номер попытки и текущее время приложение назначает самостоятельно. Экспорт CSV включает также attempt, submitted_at и max_score; при обратном импорте эти три поля не задают номера и даты новых попыток. Импорт добавляет записи и не заменяет существующие. Для каждой некорректной строки выводится причина, остальные строки обрабатываются дальше. CSV использует запятую и кодировку UTF-8; поддерживается BOM и стандартное экранирование кавычками.

JSON сохраняется атомарно: временный файл создается рядом с целевым, записывается и синхронизируется, затем `os.replace` заменяет основной файл. Ошибка до замены не портит прежний JSON. CSV-экспорт записывается обычным способом.

## Ограничения

Это учебное однопользовательское приложение. Одновременная запись нескольких процессов в один файл не поддерживается. Дедлайн хранится и показывается, но не запрещает позднюю сдачу. История undo не сохраняется между запусками и занимает память пропорционально числу изменений. Поиск выполняется линейным просмотром, а рейтинг сортировкой выбором. `memory profile` начинает отдельные сеансы трассировки; последующая команда memory показывает память с начала новой трассировки. Результаты tracemalloc зависят от версии Python и размера данных.
