## Структура

```text
Labs/
├── lab_01/
├── lab_02/
├── lab_03/
├── lab_04/
└── lab_05/
    ├── README.md          # Навигация и запуск
    ├── tasks/             # Код, тесты и примеры данных
    ├── reports/
    │   ├── REPORT.md
    │   └── REPORT.docx
    └── results/
        └── RUN_RESULTS.txt
```

Во всех пяти работах используется одинаковая структура. Ранние файлы первой работы сохранены в `lab_01/archive`.

## Запуск и проверка

Нужен Python 3.11 или новее. Команды запуска указаны в README каждой лабораторной. Выполняйте их из соответствующей папки `tasks`.

В работах 1–4 проверены все 20 заданий. В работе 5 прошли 23 модульных теста и отдельные интеграционные проверки 33 команд. Вывод сохранен в папках `results`. Личные поля отчетов оставлены пустыми.
